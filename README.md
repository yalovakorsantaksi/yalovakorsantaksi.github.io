# Yalova Korsan Taksi

Yalova korsan taksi hattının kalbi iskeledir. İstanbul'dan deniz otobüsü ve feribotla gelen yolcu rıhtımdan alınıp Termal'e ya da yazlığına bırakılır. Uçak için Sabiha Gökçen'e gidilir: Yalova merkezden 60 kilometre, 50 dakika; Altınova'dan 45 kilometre.

Termal'deki kaplıca otelleri yıl boyu, Çınarcık ve Armutlu sahili yazın doludur. Armutlu 110 kilometreyle havalimanına en uzak ilçedir. Altınova'daki tersaneler bölgesine iş için gelenler de hattı kullanır.
